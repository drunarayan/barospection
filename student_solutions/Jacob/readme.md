#### Assigned Star is Mizar
My assigned star is Mizar, which is said to be the first spectroscopic binary to be discovered. In 1908 the second component of Mizar was discovered to be a spectroscopic binary as well. The Arabic name for Mizar is المئزر which means apron, wrapper, covering, or cover. Mizar and Alcor, the secondary star, were termed the "horse and rider" by the Arabians, and are a good test of minimal vision.
